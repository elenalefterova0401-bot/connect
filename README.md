
# Connect infum v2.0

Лёгкий ретро-мессенджер на Python в стиле ICQ / QIP 2005 года.

### Как запустить
1. Скачайте актуальный архив из раздела **Releases** справа и распакуйте его в любую папку.
2. **Не вытаскивайте папку `data`** — она должна лежать рядом с `.exe`.
3. Хосту (создателю комнаты) нужно сначала запустить `server.exe`, а затем всем участникам — `connect infum.exe`.

> **Важно для общения:** чтобы переписываться с другими людьми, подключитесь к одной частной сети в **Radmin VPN** или находитесь в одной локальной **Wi-Fi / LAN сети**. Узнать IP хоста можно в Radmin VPN или через команду `ipconfig` в командной строке, после чего ввести его в **«Мастер настроек»** в окне регистрации.

---

### Что нового в Connect infum v2.0
* **Мастер настроек подключения** — удобный ввод IP-адреса сервера прямо из интерфейса без правки кода.
* **Настройки профиля и звуков** — выбор собственной аватарки и замена звука входа (`login.wav`).
* **Пользовательские смайл-паки** — загрузка своих наборов анимированных `.gif`-смайлов через ZIP-архив.
* **Живой контакт-лист** — разделение друзей на статусы «В сети» и «Не в сети» со счётчиками.

### Примечания
* **Про антивирусы:** 3–6 срабатываний на VirusTotal — ложные (стандартная реакция эвристики на упаковщик PyInstaller без платной цифровой подписи). Весь исходный код открыт в репозитории.
* Общий чат пока находится в доработке — для стабильной переписки добавляйте собеседников по 6-значному ID и общайтесь в личных чатах.
