# connect
Легкий ретро-мессенджер на Python в стиле ICQ. Распакуйте архив, не вытаскивайте папку data, запустите connect.exe. 3 срабатывания антивируса — ложные (PyInstaller). Общий чат пока не работает, пишите в контакты.
ПРИМЕЧАНИЯ: ВЫШЛА НОВАЯ ВЕРСИЯ Connect infum v2.0
ДОБАВЛЕНО: настройки профиля и звуков запуска клиента, а так же функция добавления пользовательский наборов смайлов и статусы в сети и не в сети, мастер настроек подключения.
ПРЕДУПРЕЖДЕНИЕ чтобы общяться между людьми используйте радмин впн или находитесь в одной вай фай сети!
